Users and Roles
==



Starting from version 2.0, IOT Tree has improved user and role management.

Administrators can maintain the addition, deletion, and modification of users (including login passwords) in the user and role management dialog.

Perform operations such as adding, modifying, and deleting roles. Assign roles to selected users

#### 2.2 Special Users and Roles

User admin and role admin are system built-in and super administrators, and cannot be deleted. Of course, you can also set other users as admin role
